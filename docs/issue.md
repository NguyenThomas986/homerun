# Report an Issue

Found a bug or unexpected output? Report it one of two ways:

- Open a [GitHub Issue](https://github.com/NguyenThomas986/homerun/issues)
- Email **thomas.nguyen11@wsu.edu**

## What to include

The more of this you can provide, the faster it can be diagnosed:

- **Issue** — a short description of the problem.
- **Expected output** — what you expected to happen.
- **Result** — what actually happened.
- **SLURM log errors** — any errors from the `.out` / `.err` job logs, if present.
- **Command** — the exact command you ran.
- **Sample** — the dataset used (organism, number of samples, genome build).

## Template

Copy, paste, and fill in:

```markdown
### Issue


### Expected Output


### Result


### SLURM Log Errors (if any)


### Command
`your command here`


### Sample
organism / # samples / genome
```
